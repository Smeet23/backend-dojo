# Grokstack

An interactive, scenario-based way to deeply understand backend engineering and system design. Read lessons, play with interactive widgets, and answer real-world scenarios ("a user creates the same folder twice: which method, which status code, why?").

Lessons are original write-ups based on the [Backend from first principles](https://www.youtube.com/playlist?list=PLui3EUkuMTPgZcV0QhQrOcwMPcBCcd_Q1) YouTube series, and each lesson links to its source video.

**Live:** https://grokstack.vercel.app

Courses: Backend from first principles, System Design, and High Level Design. See [the original design doc](docs/plans/2026-10-10-backend-dojo-design.md).

## AI features

Locked behind the passcode (`APP_PASSCODE`) and capped at 300 calls a day (`ai_usage` table):

- **Explain it**: after each lesson quiz, 3 open questions (why / trade-off / debug), written by the AI once per lesson and saved, then graded against their key points.
- **Why was I wrong?**: explains your specific mistake after a wrong answer.
- **Ask about this lesson**: a tutor chat grounded in the lesson you're reading.
- **New questions**: fresh scenarios aimed at your most-missed topics, validated and saved for replay.
- **Mock interview**: an interviewer that asks follow-ups, then a scorecard linked to lessons.
- **Design review**: paste a design or code and get a review ranked by severity.

Models run on free tiers with automatic fallback (`src/server/ai/models.ts`): Groq `gpt-oss-120b` for short prompts and Gemini Flash for long context, each falling back to the other. Requires `GROQ_API_KEY` and `GEMINI_API_KEY`.

Lessons are fed to the models as plain text generated by `pnpm content:text` (the `dev` and `build` scripts run it).
