# Grokstack

An interactive, scenario-based way to deeply understand backend engineering and system design. Read lessons, play with interactive widgets, and answer real-world scenarios ("a user creates the same folder twice: which method, which status code, why?").

Lessons are original write-ups based on the [Backend from first principles](https://www.youtube.com/playlist?list=PLui3EUkuMTPgZcV0QhQrOcwMPcBCcd_Q1) YouTube series, and each lesson links to its source video.

**Live:** https://grokstack.vercel.app

**Status:** v1 in progress (lectures 1–5). See [the design doc](docs/plans/2026-10-10-backend-dojo-design.md).
